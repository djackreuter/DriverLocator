# DriverLocator


Easily locate non-Microsoft drivers.

Checks the following locations:<br>
`C:\Windows\`<br>
`C:\Windows\System32\drivers\`

Recursively checks:<br>
`C:\Program Files\`<br>
`C:\Program Files (x86)\`

Drivers that are not from common vendors are highlighted green.
